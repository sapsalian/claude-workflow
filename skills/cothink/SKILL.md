# /cothink 워크플로우

## 요청
$ARGUMENTS

## Step 1: 컨텍스트 파악

요청과 관련된 코드/파일/상황을 먼저 파악:
- 관련 파일 탐색
- 현재 상태 이해
- 영향 범위 파악

## Step 2: Q&A 라운드 (최소 3회)

각 라운드 시작 전 아래 형식으로 고려사항 정리 후 AskUserQuestion 호출:

```
## 고려 사항 정리 (라운드 N)

### 검토한 사항
- [사항]: [판단]

### 자동 결정한 사항 (명백한 기술적 사실만)
- [사항]: [결정] — 이유: [근거]

### 사용자에게 질문할 사항
- [질문들]
```

규칙:
- 3라운드 필수. 이전 라운드 결정이 새 고려사항을 파생시킬 수 있음
- 3라운드 후에도 미결 사항이 있으면 계속 진행
- 트레이드오프가 있는 결정은 반드시 질문. 명백한 기술적 사실만 자동 결정

## Step 3: 결정사항 요약

```
## 확정된 결정사항

- [결정 1]
- [결정 2]
- ...
```

## Step 4: 요청 실행

확정된 결정사항 기반으로 요청 수행.
실행 중 예상치 못한 사항 발생 시 추가 Q&A 허용.
